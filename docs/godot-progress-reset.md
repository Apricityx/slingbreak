# Godot 游戏数据重置

设置 → 游戏进度下方提供红色 **重置游戏数据** 按钮。首次点击仅打开二次确认弹窗，说明清空范围与不可撤销性；只有点击 **确认重置** 才执行。

- 弹窗默认聚焦「取消」。取消、Escape 或点击弹窗外部会返回原设置页，并恢复滚动位置；进度不变。
- 清空关卡、金币、累计与最佳记录、基础升级、无尽阶位、技能、刷新次数、成就与关卡规则历史，回到第 1 关技能选择。
- 主题、音量、性能模式等本机偏好保留。已导出的外部存档文件不受影响。
- 重置同时取消旧箭矢、延迟技能任务、Boss 战斗和清场过渡，避免旧局奖励或操作锁进入新游戏。
- 生产入口同步完成存档：先等待旧自动保存线程与排队写入，再原子替换为新进度；写入失败会显示错误信息。

真实输入与持久化回归：

```bash
python3 godot/tools/run_checks.py --godot godot --gui --test settings_reset_test
```

覆盖浅／深主题、完整／简化动画、取消及焦点返回、确认重置、旧自动保存排队和重新读档；测试存档及真实截图输出到忽略目录 `agent-tmp/godot/settings-reset/`。
