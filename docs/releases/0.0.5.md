# 弓引力 v0.0.5

Android 启动器使用的 Godot 独立资源包。下载 Release 附件中的 **`game.pck`**；
`game.pck.sha256` 和 `release-manifest.json` 用于校验与版本追溯。

## 本次更新

- 新增 24 种变体关规则，按无重复牌组轮换；关卡介绍、结算与存档保留对应规则状态。
- 更新深渊之眼、时之君主、星渊巨蟒与熔炉巨像的战斗表现、反击机制和分层采样配乐。
  熔炉巨像仍未加入自然 Boss 牌组，可通过开发者模式进入。
- 整合第七至第九批 12 项金色技能特效；累计 36 项技能已完成 V2 升级，尚非全部 81 项。
  普通碎砖、爆炸砖采用 GPU 批量效果，碎砖收入按箭矢归并展示。
- 增加品牌启动画面、真实准备完成后的短交接与屏幕比例适配；首轮选卡不会在遮罩后提前播完。
- 整合启动器圆环控件、JNI 方法发现兼容、真实 ready 门禁和保存确认／重试。
- 增加开发者面板，支持技能、升级、关卡与 Boss 调试；修改进度前请先导出备份。
- 更新弓箭、冰冻、碎砖、爆炸及选卡 UI 采样音效，随包保留来源、许可与改编说明。
- 修复随机障碍占用熔炉燃料槽的问题，并隔离赏金回归夹具中的变体关干扰；
  音频编码回归分别校验 Ogg 精确时长与旧版 FFmpeg 的尾块填充。

## 配套与兼容性

- Godot **4.7.2 stable**，Android PCK，内部版本号 **0.0.5**。
- 沿用 `Resource/engine.apk`，本次不更新或重新分发引擎 APK。
- 版本标签对应本次完整源码提交，发布包从同一份源码导出，不再仅标记本地未提交快照。
- PCK 更新不会同时更新启动器 APK；原生返回、Activity 切换等宿主行为仍由配套启动器实现。
- 本次桌面原生与图形回归、打包资源和启动冒烟检查不能替代 Android 新包真机验收，
  也不能作为手机帧率或扬声器听感结论。

发布时的文件大小、SHA-256、源码提交和实际检查结果见 Release 说明及 `release-manifest.json`。
