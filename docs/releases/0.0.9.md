# 弓引力 v0.0.9

Android 启动器使用的 Godot 独立资源包。下载 **`game.pck`**；
`game.pck.sha256` 与 `release-manifest.json` 用于文件校验与源码追溯。

## 本次更新

- **长期成长平衡**：无尽伤害采用对数平方增长，碎砖与连击收益采用递减曲线；调整无尽价格，让持续升级与关卡耐久保持接近的增长速度。
- **基础升级更实用**：补强箭矢后 12 级伤害并降低后段价格，基础树原价总成本降至 1,561,015。刷新容量升级立即赠送一次刷新，后续补充周期可缩短至每 3 关一次。
- **收敛经济叠加**：议价改为八折，锻造每关首次符合条件的购买额外提升一级；成就叠满倍率由 ×9.5 调整为 ×4，并同步说明文字。
- **Boss 成长回报**：本体与相关机关按关卡耐久预算确定生命，不再跟随玩家伤害同步变厚，永久升级与战斗构筑能真正提高相对输出。
- **设置新增数据重置**：红色「重置游戏数据」按钮配备二次确认，说明清空范围；取消、Escape 或点击弹窗外返回设置，确认后清空游戏进度并回到第 1 关。
- **重置与存档更可靠**：确认重置后立即保存，正确等待旧自动保存队列；同时清理旧箭矢、延迟奖励、Boss 战斗与清场过渡。浅深主题的危险按钮与确认焦点均已适配。
- **长线与界面回归**：增加长期经济模型、刷新与 Boss 数值检查，以及危险按钮真实输入、取消、持久化和重新读档覆盖。升级树预览与实战共用公式，高阶微小增益保持可见。

## 配套与存档

- Godot **4.7.2 stable**，Android PCK，内部版本 **0.0.9**；沿用现有 `Resource/engine.apk`。
- 更新保留现有金币、已购基础等级、无尽阶位和刷新库存，属性按新平衡曲线计算；降价不追溯退款，刷新赠送不追溯补发。
- 数据重置只在玩家点击「确认重置」后执行；主题、音量、性能模式等本机偏好保留。
- 长线结果来自固定击杀分布的收入模型，不代表实玩通关时间或胜率；桌面原生与图形检查的范围在发布清单中列明。

本次检查结果、源码提交、文件大小与 SHA-256 在 Release 说明和 `release-manifest.json` 中列出。
