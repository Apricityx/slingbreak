# 弓引力 v0.0.6

Android 启动器使用的 Godot 独立资源包。下载 Release 附件中的 **`game.pck`**；
`game.pck.sha256` 和 `release-manifest.json` 用于校验与源码追溯。保留原有 v0.0.5，本次使用独立的新版本标签。

## 本次更新

- 统一 12 个技能的爆炸表现：爆裂箭头、地裂余震、延迟引爆、脉冲雷区、冰火连爆、连环殉爆、轨道轰炸、天幕裁决、潮汐回卷、吞星熔炉、城墙粉碎机、超新星爆发，不再调用旧火团。
- 与爆炸砖共用新版 GPU 爆炸：白热核心、火球团、火舌、冲击波、碎块、火星和烟团，约 1.1 秒完成收尾；移除共用引爆路径重复叠加的旧圆环。
- 保留原有伤害、命中点、半径、触发延迟、音效与箭矢归属；冰火连爆的冰层、地裂余震的裂隙、超新星的目标热印和潮汐回卷的三次回卷环保留，碎冰风暴继续使用冰晶冲击。
- 爆炸砖与技能共用固定 16 事件 GPU 批次，更新启动预热与简化动效路径，补充真实技能触发、伤害边界、生命周期、reset 和图形回归覆盖。
- 补齐技能预览注册，提供真实 Godot 渲染的浅色、深色和简化模式循环动图；本次仅统一共用爆炸，不代表其余所有技能均已完成完整 V2 重设计。

## 配套与兼容性

- Godot **4.7.2 stable**，Android PCK，内部版本号 **0.0.6**。
- 沿用 `Resource/engine.apk`，本次不更新或重新分发引擎 APK、启动器 APK，也不发布旧 Web 版本。
- 版本标签、资源包和 `release-manifest.json` 指向同一份已提交源码。
- PCK 更新不会修改宿主的原生返回或 Activity 切换行为，也不会迁移或删除存档。
- 桌面原生与图形回归、包内资源和启动冒烟不能替代新包的 Android 真机验收，不作为手机帧率或扬声器听感结论。

文件大小、SHA-256、源码提交和本次实际检查结果见 GitHub Release 说明及 `release-manifest.json`。
