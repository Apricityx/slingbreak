# 弓引力 v0.0.8

Android 启动器使用的 Godot 独立资源包。下载 **`game.pck`**；
`game.pck.sha256` 与 `release-manifest.json` 用于文件校验与源码追溯。

## 本次更新

- 金币升级页重做为整页「星铸命盘」：中央星核、分叉星轨、里程碑与四章导航融入全屏星图，保留单一购买操作、触控和键盘导航。
- 21 个基础节点、89 次强化全部完成后解锁三项无尽成长：每阶基础伤害 +0.08、碎砖收益系数 +0.12，或连击增幅 +0.01 与倍率上限 +0.25，均实际作用于战斗与收益。
- 无尽成长采用递增多项式价格，支持议价与每关一次锻造；独立保存阶位，旧等级和金币不重置，旧存档自动补齐零阶数据。
- 强化与解锁沿真实弯曲星轨反馈；全树完成点亮星核，无尽每十阶触发星耀冠冕与突破音效，简化模式保留确认效果。
- 校正规则说明中箭矢归属伤害的含义，扩展全部 24 种规则在浅深两主题下的完整说明、核心条件和布局回归。
- 扩展升级树实战数值、交易、存档、极高阶位、全页布局与真实输入测试；选卡闪光测试改为观察真实锁定事件，不改生产动画节奏。

## 配套与兼容性

- Godot **4.7.2 stable**，Android PCK，内部版本 **0.0.8**。
- 沿用 `Resource/engine.apk`，本次不更新引擎或启动器 APK，不发布旧 Web 版本；旧发布与附件保持不变。
- 存档格式版本仍为 1；不迁移或删除存档，不回收原有金币与已购等级。非零无尽阶位要求全部基础节点完成。
- 桌面原生、真实图形与打包冒烟不替代 Android 真机验收，不作为手机性能、音画延迟或触摸手感结论。
