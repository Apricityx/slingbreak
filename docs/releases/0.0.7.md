# 弓引力 v0.0.7

Android 启动器使用的 Godot 独立资源包。下载 Release 附件中的 **`game.pck`**；
`game.pck.sha256` 和 `release-manifest.json` 用于校验与源码追溯。保留原有 v0.0.6，本次使用独立的新版本标签。

## 本次更新

- 金币商店替换为三路线、三阶段、21 节点、89 次强化的成长树；节点有可见前置与点亮连线，
  选择与购买分离，底部显示真实价格和属性前后值，阶段标签可直达各层。
- 成长树使用原创分层矢量徽章，并以 3× 栅格化缓存；强化、节点完成、传奇突破三档演出
  分别使用局部闪击、晶面碎片、解锁能量与专属音效，简化模式保留主体确认。
- 新增 5 段 48kHz Vorbis 升级音效，来自固定哈希的 CC0 实录采样；制作脚本与来源清单一并随包。
- 关卡规则改为顶部常驻规则栏：随时查看完整说明并暂停，首次遇见才弹介绍卡，
  选技能页保留入口；封印／折射／坚壁核心的提示改用真实命中条件。
- 规则按关卡分层开放（1–5、6–10、11–17、18–20、22／24／26／28），已洗牌进度不丢失。
- 重做规则数值与说明：节拍每拍只计一次并独立推进，接入真实采样 tick；
  要塞增加可击碎弱点，封印砖增加外置标记；奖池、加注、连杀赏、限箭、沙漏、过热
  按逐次发射归属结算，分裂与延迟箭不能替其他发射保留资格。
- 拉弦间隔满级由 0.10 秒改为 0.40 秒，限制持续射击吞吐；已购等级保留，按新公式重算。
- 进度导入／导出改用系统原生文档选择器（Android SAF），直接读写 `content://` URI，
  不申请共享存储权限；导入前校验存档结构，取消不影响当前进度。

## 配套与兼容性

- Godot **4.7.2 stable**，Android PCK，内部版本号 **0.0.7**。
- 沿用 `Resource/engine.apk`，本次不更新或重新分发引擎 APK、启动器 APK，也不发布旧 Web 版本。
- 版本标签、资源包和 `release-manifest.json` 指向同一份已提交源码；v0.0.6 标签及附件保持不变。
- 存档格式版本仍为 1，旧等级直接承接；未开始的节点按树前置解锁，不回收金币或已购等级。
- PCK 更新不会修改宿主的原生返回或 Activity 切换行为，也不会迁移或删除存档。
- 桌面原生与图形回归、包内资源和启动冒烟不能替代新包的 Android 真机验收，不作为手机帧率、扬声器听感或触摸手感结论。

文件大小、SHA-256、源码提交和本次实际检查结果见 GitHub Release 说明及 `release-manifest.json`。
