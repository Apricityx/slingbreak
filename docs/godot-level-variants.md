# Godot 本关特效：规则、提示与结算

Godot 为唯一玩法实现。规则在 `godot/src/core/variants/`，宿主为
`godot/src/core/variants.gd`。本次调整不修改旧浏览器端。

## 玩家可见信息

- 顶部关卡行常驻规则名称和实时状态：倒计时、已用／目标箭数、奖池、热度、赌注等。
- 点击规则栏打开完整说明，并暂停当前关卡；关闭后恢复之前的暂停状态。
- 首次遇见规则才单独展示说明卡，`state.variantSeen` 随存档持久化。重遇时直接进入三选一，选技能页保留规则入口。
- 封印／折射／坚壁核心的显现提示、核心标签和右侧状态使用实际命中条件，不再统一宣称“命中即可清场”。
- 原短暂 toast 移至底部收益区域右侧，避免覆盖常驻规则。

## 分层开放

最早出现的关卡如下。已生成的存档关卡继续使用原规则；仅新关卡抽牌应用分层。

| 关卡 | 新开放规则 |
| --- | --- |
| 1–5 | 淘金热、熔合、伪装砖、塌方、悬赏令，依次开放 |
| 6–10 | 侧风、游移核心、多米诺、低重力、重箭，依次开放 |
| 11–17 | 连杀赏、封印核心、要塞、弹射蓄能、坚壁核心、折射核心、闪移核心，依次开放 |
| 18–20 | 压境、沙漏、限箭挑战，依次开放 |
| 22 / 24 / 26 / 28 | 过热 / 奖池 / 节拍 / 加注 |

宿主保留已洗牌的未抽规则，暂时跳过未开放项；当前可用项耗尽时只重洗开放项。
可选规则超过一种时不连续重复。全部开放后维持完整无重复牌组。

## 机制调整

### 节拍

- 首箭定拍，之后节拍独立推进；合拍不重置相位。
- 前后各 0.16 秒为窗口，每个拍点最多计一次，提前／延后窗口共享同一拍点编号。
- 已计分窗口内多射不额外计分、不重复加伤；窗口外射击重置连拍。
- 节拍周期在下一拍边界按连拍从 1.3 秒缩短至 0.9 秒；使用已有 CC0 实录 `ui-tick-1.vorbis` 做独立 `cadence_tick` 提示，不改变普通 tick 的音效路由。
- 最佳连拍仍提供最高 ×1.8 核心奖金。

### 逐次发射归属

`shot_rule.gd` 将主箭、沿 `source` 链的分裂／衍生箭、延迟任务及持续技能场归到同一次发射。
只有本次发射的所有实体与工作结束才结算；其他连射不能保住它的空箭惩罚。

- 奖池：每箭发射时记录风险基数。未碎砖，扣当时奖池的 30%（不超过当前未兑现奖池），不会扣已入账金币；后来获得的收入不被追溯计入风险。
- 加注：本次达到 3 杀立即 +0.5，最多 ×4，每次发射最多加注一次。不足 3 块时可以本次清空余砖达标。未达标箭结束则赌注归 ×1。
- 命中核心直接兑现，最终箭不被额外判空；存档不保留飞行实体，因此恢复取消未完发射的义务，不凭空罚款，保留已兑现的加注和已累积的奖池。

### 收益与压力

- 连杀赏：前两杀及无箭矢来源的击杀恢复正常收益；同一箭第 3 杀起 ×2，不再隐藏半价惩罚。
- 限箭：目标来自当前砖血、核心阈值、伤害和穿透的保守接触次数估算，而不是其他规则关的历史用箭量；首箭前随装备更新，首箭锁定。目标内 ×2，每省一箭 +0.1（上限 ×3）；每超一箭 -0.15，下限 ×1。
- 沙漏：首箭后，每次冷却结束另有 0.8 秒瞄准宽限，之后每秒 -0.1 奖金，×2.5 至 ×1。场上旧箭不再停止决策计时；暂停仍冻结。
- 过热：冷却量为 `0.18 × dt / 基础拉弓间隔`，不同升级阶段按可发射机会归一化；热箭减伤、过热扣奖金及恢复条件均写入说明。
- 要塞：普通护甲从 ×2.5 降为 ×1.6；最多 3 块橙色弱点保持原血量，分散在障碍附近。击碎弱点移除 160 范围障碍，并对邻砖造成基础伤害 ×1.5；奖金仍为 ×2。
- 封印砖增加外置实心菱形和更清晰的边框，避免目标只靠淡线辨识。
- 低重力／弹射蓄能的说明明确初始减伤、成长幅度、上限和奖金；无箭矢来源的伤害不变，但沿箭矢归属的范围技能仍受该箭的倍率影响。悬赏令明确目标血量与逐箭递减，压境明确底线不会直接判负。

## 验证与预览

新增 `native_variant_design_test.gd` 和 `native_variant_ui_test.gd`，纳入默认原生检查：

- 重叠发射、延迟技能、分裂箭归属与核心兑现。
- 快射不能刷拍，提前／延后窗口不能双计，拍点存档不重复领取。
- 各升级阶段过热、沙漏宽限、状态无输入刷新。
- 首次／重遇介绍、嵌套返回、阅读暂停、浅深主题规则栏及核心条件。
