# Godot 开发者模式

## 解锁

打开设置，滚动到最后的「音效鸣谢」，连续点击标题或鸣谢文字 **7 次**，相邻两次间隔不超过 **450 毫秒**。设置末尾会出现「开发者模式」按钮。鼠标和触屏都可以使用，鸣谢中的来源和许可链接保持原用途。

解锁状态、启用状态和覆盖配置保存在本机设置中，不随进度导出；重新启动后仍然保留。

## 面板

- 开关：启用 / 停用覆盖；「停用并清除全部覆盖」恢复正常计算公式并清除逐关数量配置，但保留已解锁入口。
- 存档：金币、累计收益、最佳收益、刷新次数，以及全部七项商店升级。
- 战斗：最终伤害、箭速、穿透、射击间隔、砖块基础生命、特殊砖比例、过关奖励、连击增幅 / 上限、砖块收益倍率、商店价格倍率、核心解锁击破比例。每项可以单独恢复默认公式。
- 技能：按照当前槽位数任意选择完整技能目录，忽略最低解锁关卡，支持移除、替换和重排；不允许重复技能。技能槽位可在升级区域调整。
- 关卡：跳转到 1–100000 关；为任意关卡单独保存 1–77 个砖块的配置。需点击「跳转 / 重建所选关卡」才会将数量应用到场上。未配置关卡使用原生成规则。Boss 专属布局仍由 Boss 系统生成。
- Boss：启用后可选择深渊之眼、熔炉巨像、星渊巨蟒或时之君主，点击「立即开始 Boss 战」在当前关卡直接挑战，无需到达百层关卡。保留金币、升级和装备技能，清空本关战斗并关闭面板；战斗正常存档，跳转 / 重建所选关卡可清除 Boss 指定。

## 生效与存档

打开面板时暂停游戏，关闭后恢复之前的暂停状态。伤害等参数用于后续计算，不追溯修改已发出的箭；砖块生命 / 特殊比例需要重建。应用技能会重建本关，清理旧技能的延迟任务、被动效果和旧战斗对象。

**修改金币、升级、技能或跳关会改变正常游戏进度，自动存档也会保存这些改动。请先在设置中导出备份。清除覆盖不会撤销这些进度改动。** 开发者配置独立存储，但不是独立的沙盒存档。

所有输入使用有限范围与类型校验，拒绝 NaN、无穷数、重复技能、非法 ID 和越界关卡；不开放任意对象属性写入，也不放宽导入存档校验。这里覆盖的是列出的游戏参数，不包括渲染动画常量或各技能代码中的所有内部常量。

## 回归

```sh
python3 godot/tools/run_checks.py --godot godot
python3 godot/tools/run_checks.py --godot godot --gui --test developer_test
```

开发者测试覆盖快速点击、解锁门禁、数值校验、技能替换、精确砖块数量、配置恢复、存档有效性、面板应用与暂停恢复；图形模式还生成浅色 / 深色截图到 `agent-tmp/godot/preview/developer-*.png`。
