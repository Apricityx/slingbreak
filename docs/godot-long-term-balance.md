# Godot 长期数值平衡（2026-11-13）

## 目标

让永久成长与内容推进接近同速：普通玩家稳定得到升级，强构筑仍更快，但不会靠两项无限经济属性相乘把金币和伤害越滚越快。无尽阶段保留无限阶位；射速、穿透、槽位保持机械上限。普通砖的生命公式与关卡解锁顺序保持现有内容节奏。

验收范围是生产公式、交易、奖励归属与存档，以及明确假设的收入模型。关卡中的瞄准、特殊砖连锁、Boss 机制和玩家通关时间仍属于实战表现，不把固定击杀分组的收入模型称为自动通关。

## 成长曲线

统一实战与 UI 数据源为 `godot/src/core/upgrade_tree.gd`。设基础箭等级为 `r`、无尽阶位为 `n`：

```text
t(n) = log₂(1 + n/12)
e(n) = 12 ln(1 + n/12)

基础伤害 = 2 + 0.65 log₂(r+1) + 0.08 clamp(r−12, 0, 12)
无尽伤害增益 = 0.65t + 0.13t²
无尽碎砖系数增益 = 0.12e
无尽连击增幅增益 = 0.01e
无尽连击上限增益 = 0.25e

下一阶价格 = ceil(min(10^15, 首价 × (1+n/12)^1.15))
首价：伤害 240,000；碎砖 180,000；连击 50,000
```

三种增益都持续增加、边际递减。伤害增量的二阶导数为负，因为 `0.26/ln(2) − 0.65 − 0.26t < 0`（`t≥0`）。收益和连击由线性改为对数后，两者相乘的长期增收从 `n²` 降到 `ln²(n)`。

单次价格为 `Θ(n^1.15)`，累计投入为 `Θ(n^2.15)`。仅核心奖金的累计收入为 `Θ(L^2.15)`，意味着持续投入某一路线时阶位约与关卡同阶。伤害为 `Θ(log² n)`，与普通砖 `Θ(log² L)` 的耐久同阶。经济投入会改变系数和缓慢变化的对数项；不能据此假定所有玩家的通关时间相同。结论适用于正常存档范围、价格封顶前；门禁用有限的 10,000 关模型验证实际量级。

连击首价下调，使满基础树、三连模型的首阶碎砖／连击资金效率接近（约 1.27 倍），而不是旧版约 3.6 倍。高连锁依然更适合投资连击；随着各自价格增长，策略存在轮换空间。

## 基础树与临时技能

- 13～24 级箭矢每级额外增加 0.08 基础伤害，满级约 5.979；后段价格倍率从 1.4 降到 1.32。基础树原价合计从 1,968,345 降到 **1,561,015**。
- 刷新四阶价格为 **800 / 4,000 / 12,000 / 32,000**。每次购买即获得一次刷新；补充周期随基础等级为 **5 / 5 / 4 / 4 / 3** 关，容量仍为 1～5。以 `rerollGrantLevel` 记录最近一次补充，即使仓库已满也推进时钟，不累计隐藏补充，不在重载时重复发放。
- 折扣从六折改为八折；锻造从额外两级改为额外一级。仍是每关首次符合条件的购买生效，不跨基础节点；无尽也生效。技能槽／刷新容量不触发也不消耗锻造。
- 击杀成就四个档位的额外倍率改为 **0.15 / 0.20 / 0.30 / 0.45**；技巧成就分别为 0.2 或 0.3。所有 12 项成就叠满的单箭成就倍率由 ×9.5 降到 **×4**，成就仍按箭追补、不会重复支付。实际数值来自 `assets/achievements.json`，展示随数据更新。
- 永久属性、升级前后预览及按钮购买级数共用真实公式；晚期小数提升使用更高显示精度。

## Boss 成长回报

Boss 本体和与装备相关的机关血量改用内容预算：

```text
参考伤害 = max(2, 本关普通砖基础生命 / 3)
本相生命 = ceil(参考伤害 × (24 + 6 × 相位))
```

参考伤害不读取玩家永久伤害或本关技能。普通升级不会再令下个 Boss／下一相同比变厚；升级能提高对本体的相对输出。各 Boss 的破盾／时机、阶段数与已有减伤节奏继续生效。新建机关使用同一参考伤害。旧存档中的在战 Boss 保留已保存生命，换相后采用当前规则。

运行：

```bash
godot --headless --path godot --audio-driver Dummy --script res://tools/audit_upgrade_economy.gd
```

输出：`agent-tmp/godot/upgrade-economy.json`（忽略产物）。模型调用真实 `reward`、`evaluate_achievements`、`cost`、`buy`，每关固定 40 块普通砖，没有实际物理通关。普通基线不计技能、特殊砖、成就和变体加成。
